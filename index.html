CVE · ModerateApple

Build-context path traversal

apple/container · CVE-2026-64777

Apple's Swift Linux-container runtime resolved build-context symlinks against the host during filesystem sync, so a malicious builder peer could read files outside the build context by name. CWE-22, CVSS 4.3. Fixed in container 1.2.0; a sibling advisory covers the same resolver's JSON walk mode.
